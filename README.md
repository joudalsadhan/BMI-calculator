# BMI Calculator

A simple and user-friendly web application that calculates Body Mass Index (BMI) based on the user's weight and height.

## Features

- Collects the user's name, email, and gender.
- Accepts weight in kilograms and height in centimeters.
- Calculates the user's BMI.
- Displays the BMI value and weight category.
- Provides health notes based on the selected gender.
- Includes a Reset button to clear the entered information.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the `BMI.html` file in a web browser.
3. Enter the required information.
4. Click **Calculate BMI** to display the result.
